# 可选的 Windows 微信启动器

在同一台 Windows 电脑上使用两个微信号时，可以用这个独立小工具请求启动另一个官方微信窗口。首次登录由账号持有人按微信提示完成。关闭启动器后微信可以继续运行。

在此目录打开 PowerShell，运行以下命令。构建脚本使用 Windows 的 .NET Framework C# 编译器，根据微信安装信息选择客户端并打印完整路径。

```powershell
.\Build.ps1
.\LocalWeixinLauncher.exe
```

安装在自选位置时，可向 `Build.ps1` 传入 `-ClientPath "完整安装目录\Weixin.exe"`。每次点击“启动官方微信”或“请求再开一个窗口”时，程序核对当前文件的 Windows Authenticode 签名、腾讯发布者和微信产品标识，核验通过后对同一路径发出一次普通启动请求。正常更新可以保留启动器；移动安装目录后重新构建。

窗口数量由微信决定。Windows 微信 4.2.0.53 的实测从一个窗口变为两个独立主窗口，原微信会话保留。启动器与小汐的消息接收器分别核验兼容性。

`--self-test` 可以单独验证客户端和窗口计数，结果写入启动器旁的 `launcher_self_test.json`。要重复运行自检，请先移走上一次报告。
